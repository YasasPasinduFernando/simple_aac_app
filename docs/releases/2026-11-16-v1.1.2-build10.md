## 3. Key Enhancements & Fixes in v1.1.2 (Build 10)

### 3.1 100% Comprehensive Settings & Media Backup/Restore Round-Trip
* **Color Vision Accessibility Settings Persistence:** Fully incorporated `colorBlindType`, `colorBlindBorderWidth`, `colorBlindBorderColor`, `colorBlindBoldText`, and `colorBlindFilterImages` into `_buildBackupSettings()` and `_applyRestoredBackup()`. When restoring, invokes `ThemeAccessibility.saveColorBlindSettings()` and sets `ThemeAccessibility.colorBlindMode`.
* **Dark Mode Persistence on Restore:** Invokes `ThemeAccessibility.setDarkMode()` to ensure SharedPreferences syncs immediately on backup restoration.
* **Custom Categories Preservation:** Explicitly packages `customCategories` into `settings.json`, ensuring newly created custom categories are 100% restored even if zero cards currently belong to them.
* **Media & Files SHA-256 Match:** Card photos, illustrations, animated GIFs, and voice recordings are packaged into `files/` and restored with zero corruption, path traversal protections, and duplicate collision avoidance.

### 3.2 Visible Cards Dialog Empty State Handling
* Eliminated the `if (total == 0) return;` early exit guard in `_showVisibleCountDialog()`, allowing the dialog to open properly when a selected category has 0 cards.
* Display friendly empty state card with icon, title (`"No cards found in \"<category>\" category"`), and subtitle explaining cards can be created in Edit Mode first.
* Hides `Select all` / `Clear all` buttons when card count is 0 to prevent redundant taps.
* Updated `VisibleCardsPreview` to show `"No cards in this category"`.

### 3.3 TTS Bar Settings & Separate Button Switches
* Renamed dialog to "TTS Bar Settings".
* Independent toggles for "Show Delete Button" and "Show Clear Button" (both default enabled).
* Real-time Live Preview reflects height scaling and independent button visibility.

### 3.4 Child-Safe Press-and-Hold Unpin Guard
* Board unpinning strictly requires 700ms press-and-hold with haptic feedback vibration.

### 3.5 Interactive Trilingual Onboarding Tour
* 9-step guided tour explaining navigation, cards, sentence building, TTS, and settings.
* Automatic drawer close on Step 4 advance and back-navigation.
* Permanent "Interactive App Guide" replay option in Settings Drawer.

### 3.6 Toolchain & Build Hardening
* Upgraded to Android Gradle Plugin 9.0.1 and Gradle 9.1.0.
* Verified 16 KB ELF page alignment for native libraries (Android 15 compliance).
* Version code bumped to `10` (`1.1.2+10`).
