## 3. Key Enhancements in v1.1.1 (Build 9)

### 3.1 TTS Bar Settings & Independent Action Controls
* Renamed "TTS Bar Sizing" dialog and drawer item to **"TTS Bar Settings"**.
* Introduced independent, separate toggles for **"Show Delete Button"** and **"Show Clear Button"** (both default enabled).
* Integrated real-time Live Preview reflecting size scaling and independent button visibility.
* Maintained 100% backward compatibility with legacy `showTtsActions` persistence and backups.

### 3.2 Interactive First-Run App Guide & Onboarding Tour
* 9-step trilingual interactive onboarding walkthrough (`TutorialService`).
* Visual hole-punch spotlighting (`HighlightPainter`) dynamically framing key targets.
* Automatic drawer close and edit mode synchronization across Step 4 advance and back-navigation.
* "Replay Quick Tour" option permanently available in Settings Drawer under Help & Guides.

### 3.3 Child-Safe Press-and-Hold Unpin Protection
* Board unpinning now strictly requires a 700ms press-and-hold with haptic vibration feedback.
* Accidental single taps by children or learners no longer unpin the board.

### 3.4 Color Vision Deficiency Support & Card Adaptation
* Full support for Protanopia, Deuteranopia, Tritanopia, and Monochromacy palettes.
* Real-time image color filtering adapting photo cards and illustrations for color-blind users.
* High-contrast card border ring customizer (1–10px thickness, auto-contrast or custom colors).
* High-contrast mini palette preview chips in Settings Drawer.

### 3.5 Interactive Add Category Modal
* Live category badge preview.
* Quick preset chips (Food, School, Feelings), icon selector, color accent picker.
* Full card assignment checklist with search filter, Select All, and Clear Selection.

### 3.6 Direct Runtime Permission Requests
* Native Android runtime dialogs for Camera and Microphone triggered on first use without forcing user to system settings.

### 3.7 Toolchain & Build Hardening
* Upgraded to Android Gradle Plugin 9.0.1 and Gradle 9.1.0.
* Optimized R8 full-mode shrinking with explicit keep rules for offline ML Kit models.
* Verified 16 KB ELF page alignment for native libraries (Android 15 compliance).
