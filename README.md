# Simple AAC App

This is a scaffolded Augmentative and Alternative Communication (AAC) Flutter app.

Quick start:

```bash
# From the project root
flutter pub get
flutter run
```

iOS: `cd ios && pod install` before `flutter run` on a real device.

Files created include core Dart files under `lib/`, platform manifests under `android/` and `ios/`, and `pubspec.yaml`.
